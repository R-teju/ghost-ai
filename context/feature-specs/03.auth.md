Override Clerk appearence variables using the app's existing CSS variables.Do not hardcore colors.

- left: compact logo,tagline,short text-only feature list
- right: centered clerk from
- small screens:from only
- no gradients
- no oversized hero sections
- no feature cards
- no scroll- heavy layouts

Keepp the layout minimal and proffessional.
## implementation

wrap the root layout with `ClerkProvider` using Clerk's `dark` theme.

Create sign-in and sign-up pages using Clerk components.

use `proxy.ts` at the projet root, not `middleware.ts`

Define public routed using the existing sign-in and sign-up env vars.protect everything else by default.

Update `/`:

- authenticated users redirect to `/editor`
- unauthenticated users redirect to `/sign-in`

Keep Clerk's default user menu and profile flows intact.Do not rebuild or heavily customize Clerk internals.

Use existing Clerk env vars.Do not rename or invent new ones.
